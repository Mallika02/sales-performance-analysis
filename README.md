Sales analysis project using Python, pandas, SQL, and Tableau Public

# Sales Performance Analysis

## Project Overview
Analyzed 120 simulated sales records from September 2026 to evaluate product performance, revenue, and daily sales trends.

## Tools
- Python
- pandas
- SQL (SQLite)
- Tableau Public

## Analysis
- Calculated revenue for each sales record using quantity and unit price.
- Used SQL queries to summarize total revenue, revenue by product, units sold, and daily revenue.
- Checked the dataset for missing values.
- Created visualizations and a Tableau dashboard to explore sales performance.

## Key Findings
- **Total revenue:** $86,625
- **Highest-revenue product:** Laptop, generating $50,400.
- **Highest unit sales:** Headphones, with 55 units sold.

## Dashboard
The Tableau dashboard summarizes revenue, units sold, and daily sales trends.

## Project Files
- `Sales.ipynb`: Python analysis and SQL queries.
- `simulated_sales_data.csv`: Original simulated dataset.
- `sales_with_revenue.csv`: Dataset with calculated revenue.

## Dataset Disclaimer
The dataset is simulated and was created for portfolio and learning purposes. The findings do not represent actual business sales.
